YOGESH SHARMA — CAREER PORTFOLIO

Files
- index.html: portfolio page
- styles.css: responsive styling

How to view locally
1. Keep index.html and styles.css in the same folder.
2. Double-click index.html, or right-click and open it in your browser.
3. The page uses Google Fonts when internet access is available; it falls back to system fonts offline.

Before publishing
- Confirm all project descriptions and dates.
- Add a LinkedIn URL if you want it displayed.
- Consider whether you want your phone number visible publicly.
- Add approved project photos / diagrams only if you have permission to share them.
- Confirm the exact meaning and value of any project budget or portfolio figures before adding them.

The page is static HTML/CSS and does not require a build tool or server.
